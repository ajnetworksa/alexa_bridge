🔗 Pair with Alexa (One-time)

Steps to pair your Alexa with Home Assistant:

  1. Open Matterbridge UI (button above) and copy the Pairing Code
  2. Open the Alexa app → Devices → + → Add Device → Matter
  3. Select Yes, it has a code → enter or scan the pairing code
  4. Alexa discovers all exposed entities automatically
  5. After pairing, internet is not required for device control
